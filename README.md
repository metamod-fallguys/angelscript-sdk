# AngelScript SDK for metamod-fallguys

Preserved AngelScript 2.36.1 sources and the Sven Co-op function-pointer ABI fixes
from hzqst/metamod-fallguys. Consumers use ANGELSCRIPT_SOURCE_PATH or fetch a pinned
commit. Plugins consume the headers; the game provides the runtime engine.

The original SDK build entry is angelscript/projects/cmake/CMakeLists.txt.
Upstream licensing remains in the original source headers.
